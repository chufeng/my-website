# 给其他电脑的画布同步提示词

将下面这段提示词交给 Codex 或其他支持 Infinite Canvas 的 Agent：

```text
请把当前仓库里的 Infinite Canvas 画布恢复到本机：

1. 先阅读 `canvas-sync/README.md` 的“当前婚礼开场画布内容基线”，按其中四条时间线和排版要求理解/重建画布，不要凭空改写剧情。
2. 只读取 `canvas-sync/exports/` 目录中名称以 `.safe.json` 结尾的画布导出文件。
3. 不要读取、上传或要求我提供 API Key、Connect token、Cookie、浏览器 IndexedDB 或 WebDAV 密码。
4. 如果存在安全导出文件，打开 https://canvas.best/canvas，使用“导入画布”导入目标 `.safe.json`；如果不存在，就依据 README 创建文本、布局和配置节点。
5. 如果需要继续生图，提示我在本机启动 `npx -y @basketikun/canvas-agent`，并在网页连接本机 Agent；不要替我把密钥写入仓库。
6. 生图只用 `gpt-image-2`，单张逐个生成；参考照片必须由我在本机上传，不得写入仓库。
7. 导入或重建后检查节点、连线、提示词和图片是否完整，并报告缺失项。
8. 若要把本机的新版本同步回仓库，先导出画布，再运行：
   node scripts/sanitize-canvas-export.mjs <导出文件> canvas-sync/exports/<名称>.safe.json
   只提交 `.safe.json` 和审核过的文档，不提交原始导出、API 配置或 IndexedDB 文件。
```

## 一句话版本

```text
从仓库导入 canvas-sync/exports/*.safe.json 到当前 Infinite Canvas；密钥只在本机配置，禁止上传 IndexedDB、API Key、token 或 WebDAV 密码。
```
