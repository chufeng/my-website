# 给其他电脑的画布同步提示词

将下面这段提示词交给 Codex 或其他支持 Infinite Canvas 的 Agent：

```text
请把当前仓库里的 Infinite Canvas 画布恢复到本机：

1. 只读取 canvas-sync/exports/ 目录中名称以 .safe.json 结尾的画布导出文件。
2. 不要读取、上传或要求我提供 API Key、Connect token、Cookie、浏览器 IndexedDB 或 WebDAV 密码。
3. 打开 https://canvas.best/canvas，使用“导入画布”导入目标 .safe.json。
4. 如果需要继续生图，提示我在本机启动 npx -y @basketikun/canvas-agent，并在网页连接本机 Agent；不要替我把密钥写入仓库。
5. 导入后检查节点、连线、提示词和图片是否完整，并报告缺失项。
6. 若要把本机的新版本同步回仓库，先导出画布，再运行：
   node scripts/sanitize-canvas-export.mjs <导出文件> canvas-sync/exports/<名称>.safe.json
   只提交 .safe.json，不提交原始导出、API 配置或 IndexedDB 文件。
```

## 一句话版本

```text
从仓库导入 canvas-sync/exports/*.safe.json 到当前 Infinite Canvas；密钥只在本机配置，禁止上传 IndexedDB、API Key、token 或 WebDAV 密码。
```
