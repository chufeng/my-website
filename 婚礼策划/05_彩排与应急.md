# 05 彩排与应急

## 彩排至少确认

- [ ] 三人的上台方向、站位和转身方向
- [ ] 主持人何时说话、何时让出舞台中心
- [ ] 入场音乐从哪一秒开始，新人听到什么信号迈步
- [ ] 誓言时是否拿手卡、麦克风如何传递
- [ ] 戒指由谁拿上台、放在哪里、何时递出
- [ ] 亲吻/拥抱前主持人是否明确提示
- [ ] 音乐和视频每个 Cue 的触发台词
- [ ] 仪式结束后往哪里退场，接下来进入什么环节

## 忘词处理

- 新人可以拿小卡，不要求背诵。
- 主持人准备一句提示问题，将新人带回内容。
- 若停顿超过3秒，主持人自然接话，不说“紧张了”“忘词了”。

## 设备故障

- 音乐未响：主持人继续说一句过渡台词，执行人员重新播放。
- 麦克风故障：准备第二支麦克风；主持人先把自己的递给新人。
- 视频无法播放：直接跳过，不让宾客等待排查。
- 戒指暂时找不到：主持人转入致谢或轻松问答，后台立即确认。

## 时间超时

优先压缩主持人的故事讲述和过渡语，不压缩新人的真实表达。
